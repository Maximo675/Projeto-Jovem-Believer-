# Documentos da base de conhecimento

Coloque aqui os arquivos `.docx` que devem aparecer na aba "📄 Documentos"
dentro de cada curso (pages/course.html) e que alimentam a base de
conhecimento da IA (`/api/documents`, `/api/documents/indice`).

Pelo README de `backend/knowledge_base/`, os documentos esperados são:

- Informativo Etan.docx
- Procedimento de Coleta.docx
- Protocolo de Coleta Passo a Passo.docx

O backend lê todo `.docx` que estiver nesta pasta automaticamente (não
precisa reiniciar nada além do próprio servidor) — não há passo de
"upload" pela interface ainda, é só colocar o arquivo aqui.
